## Applicazione

Estrarre lo ZIP nella radice della repository e sovrascrivere i file omonimi.

Quindi:

```bash
find . -type d -name __pycache__ -prune -exec rm -rf {} +
find . -type f -name '*.pyc' -delete
npm ci
python3 -m pip install -r requirements.txt
npm run phase2:check
npm run playtest:plan:check
npm run verify
```

`npm run verify` richiede le dipendenze Node installate. I controlli Python di G0/G1/Fase2 e il piano Fase3 sono stati eseguiti con successo nel checkout di sviluppo.

## Per chiudere G2

Usare `docs/playtest/PHASE2_RULES_TEST_SCRIPT.md`. Non sostituire le prove con simulazioni o fixture.

Servono:
- 2 Custodi indipendenti per prezzi Risonanza e ordine del round;
- 3 tester indipendenti per Sangue Tenace;
- i risultati devono essere registrati nei moduli e poi in `docs/gates/G2_EVIDENCE.md`.
