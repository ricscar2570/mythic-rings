# Piano di lancio e supporto

## Sequenza

1. Beta chiusa.
2. Blind playtest.
3. Quickstart gratuito.
4. Raccolta mailing list e feedback.
5. Release candidate distribuita a recensori selezionati.
6. Soft launch digitale.
7. Release 1.0 digitale.
8. Valutazione di stampa o crowdfunding soltanto dopo dati di vendita e domanda verificata.

## Funnel minimo

Pagina progetto -> quickstart -> iscrizione -> sessione -> feedback -> acquisto -> recensione -> supplementi.

## Supporto

- pagina errata;
- politica versioni;
- FAQ aggiornata senza introdurre regole nuove;
- aggiornamenti gratuiti per correzioni 1.0.x;
- prima patch entro 30 giorni dal lancio, se necessaria;
- rapporto a 90 giorni su problemi, adozione e priorita.
