# Gate di pubblicazione

## Gate A - Integrita editoriale

- [ ] Nessun placeholder.
- [ ] Nessuna nota di versione nel corpo del manuale.
- [ ] Glossario, FAQ e quick reference coerenti con la specifica canonica.
- [ ] Esempi numerici verificati.
- [ ] Crediti completi e autorizzati.

## Gate B - Sistema

- [ ] Tutte le regole MR-RULE hanno test automatici o controlli di consistenza.
- [ ] Bestiario valido e player-facing.
- [ ] Poteri revisionati per costi, durata, portata e azioni.
- [ ] Blind playtest superato.

## Gate C - Produzione

- [x] `npm ci && npm run release:check` passa in ambiente pulito.
- [ ] DOCX, HTML e PDF contengono gli stessi capitoli.
- [ ] PDF preflight senza errori bloccanti.
- [ ] Indice e segnalibri funzionano.
- [ ] Metadati e versione corretti.

## Gate D - Legale e commerciale

- [ ] Titolarita di testi, font e materiali verificata.
- [ ] Nome e marchio verificati.
- [ ] Dicitura PbtA verificata.
- [ ] ISBN reale o assente.
- [ ] Fiscalita, IVA, termini e rimborsi verificati.
- [ ] Quickstart e pagina di supporto disponibili.
