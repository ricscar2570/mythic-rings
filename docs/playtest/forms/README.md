# Moduli di raccolta dati — Playtest v1

I CSV sono moduli di appoggio per il tavolo; il formato canonico di archiviazione è il bundle JSON descritto in `../DATA_MODEL.md`.

- `SESSION_FORM.csv`: versione, profilo, durata e preparazione.
- `CHARACTER_LOG.csv`: Casata, risorse, Ancora e spotlight.
- `RESONANCE_LOG.csv`: ogni procedura di Risonanza, prezzi, scelta e tempo.
- `COMBAT_LOG.csv`: un record per round.
- `RULE_LOOKUP_LOG.csv`: tempi e posizione delle consultazioni.
- `ISSUE_LOG.csv`: comportamento osservato e severità, senza suggerire automaticamente una soluzione.
- `POST_SESSION_QUESTIONNAIRE.md`: debrief a caldo.

Non aggiungere colonne con nomi, email, handle, indirizzi, età esatta o altri dati personali non necessari. Se un dato aggiuntivo serve a una specifica ipotesi di test, documentarlo prima nel protocollo e nel registro delle issue.
