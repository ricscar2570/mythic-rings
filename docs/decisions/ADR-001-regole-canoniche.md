# ADR-001 - Fonte canonica delle regole

Stato: accettata.

## Decisione

`data/canonical_rules.yml` e la fonte normativa. Capitoli, FAQ e riferimenti rapidi devono riprodurla senza introdurre varianti.

## Conseguenze

Ogni modifica richiede aggiornamento del file, test e changelog. Le note di patch non compaiono nel manuale commerciale.
